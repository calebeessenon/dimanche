# Tropi Pop 🍓⭐

Jeu de puzzle Match-3 tropical, original, pour Android et iOS (Flutter).

* 100 niveaux calibrés, 6 fruits, 4 bonus + 6 combinaisons, glace et caisses
* Carte de 10 mondes, étoiles, vies, pièces, boosters, récompense quotidienne
* Fonctionne entièrement hors connexion
* FR / EN

## Démarrer

```bash
flutter pub get
flutter test
flutter run            # téléphone ou émulateur
flutter run -d chrome  # aperçu dans le navigateur
```

Documentation : [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) · [`docs/ROADMAP.md`](docs/ROADMAP.md)
