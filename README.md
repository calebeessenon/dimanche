## Premium Shop — thème WordPress WooCommerce premium (boutique de bois de chauffage)

- **Thème installable** : [`dist/premium-shop.zip`](dist/premium-shop.zip) → WordPress → Apparence → Thèmes → Ajouter → Téléverser un thème.
- **Code source du thème** : [`premium-shop/`](premium-shop/)
- **Guide complet (FR)** : [`premium-shop-dev/GUIDE-FR.md`](premium-shop-dev/GUIDE-FR.md) — architecture, direction artistique, installation, personnalisation, multilingue, tests.
- **Modèle d'import Excel/CSV (bois de chauffage)** : [`dist/brennholz-produkte-vorlage.csv`](dist/brennholz-produkte-vorlage.csv) → Produits → Importer.
- **Outils de build** : [`premium-shop-dev/`](premium-shop-dev/) (`bash build.sh` → traductions, minification, zip).

Langue par défaut : 🇩🇪 allemand — 🇫🇷 français, 🇪🇸 espagnol, 🇬🇧 anglais inclus. Compatible WPML, Polylang, TranslatePress.
